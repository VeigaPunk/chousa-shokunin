# Round 26 whole-round harm critique

Axes: operability (bounded reader/refusal/legacy behavior), freshness (date classification), calibration (registry/source correspondence and claims). Read-only review of the preregistration and base; no candidate implementation or checks were run. Ranked by likelihood of escaping the registered controls, not measured probability.

1. **High — C1 can lose a full-file NUL refusal if header parsing stops early.** The existing reader scans the bounded fd snapshot for NUL before parsing, while header parsing stops at the first `## ` (`tools/research-gate.sh:2363-2373,2414`). The preregistered C1 shape with a body after `## Body` has no NUL (`corpus/evidence/round26-measure.sh:62-66`); the existing NUL selftest has no heading (`tools/research-gate.sh:5582-5587`). A reader that returns at the heading could accept a valid header followed by NUL in the body. **Check:** a valid header + `## Body` + NUL fixture must still emit `META_ENTRY_REFUSED ... reason=nul unparsed`. **Small correction:** scan the entire bounded fd for NUL/size independently of the header parser's early stop.

2. **High — C3 may grade legacy entries despite the explicit prospective-only scope.** C3's findings are specified per entry (round26-claims.md:97-105), but the contract says criterion 6 starts at r24 and legacy entries are not graded (round26-claims.md:115-116; `corpus/QUALITY.md:17-23`). Its only population cleanliness count is POP24, not the other 24 entries (`corpus/evidence/round26-measure.sh:214-222`). **Check:** run `--registry` across all 29 frozen entries and separately enumerate pre-r24 findings; require none be represented as criterion-6 violations. **Small correction:** constrain C3 verdicts to the prospective population or explicitly keep legacy results informational/out of the criterion-6 rollup.

3. **Medium-high — C3's basename-only `used-by` match can falsely certify the wrong file.** The rule accepts a final path component equal to the entry basename (`round26-claims.md:101-103`), so `corpus/knowledge/old/foo.md` can satisfy an entry at another `foo.md`. **Check:** fixture one entry and a mined row whose sole `used-by` points to a different directory containing the same basename; it must not pass. **Small correction:** compare normalized repo-relative paths, not basenames; reject ambiguous/unresolvable target identity.

4. **Medium — invalid `--as-of` dates can be accepted or normalized, producing false freshness.** The spec requires missing/calendar-invalid values to exit 2 (`round26-claims.md:59-61`), but all six C2 controls use the valid registered as-of (`corpus/evidence/round26-measure.sh:151-165`). **Check:** a table-driven CLI control with `--as-of 2026-02-30` must exit 2 before printing per-entry freshness. **Small correction:** validate the calendar date strictly before date arithmetic; do not rely on permissive date parsing.

5. **Medium — “every existing input stays byte-identical” is broader than the output hold.** C1's digest covers only the frozen 29 knowledge entries (`round26-measure.sh:79-83`), while the claim covers every existing input (`round26-claims.md:34-37); selftest assertions often check selected substrings (`research-gate.sh:5419-5445`). **Check:** compare base/candidate stdout and exit code over every existing metadata selftest fixture, including refused and boundary cases, in addition to the frozen population. **Small correction:** retain full-output differential coverage for legacy cases, not just case PASS/name hashes.

6. **Medium — source rows can add apparent provenance without a source being opened or accurately quoted.** The round requires an opened source and Gate quote (`round26-claims.md:127-130`); the frozen contract requires the round lesson's URL, date, located quote ≤25 words (`/home/vgpnk/Projects/shokunin/CORPUS.md:112-115`). Prior source correction already found imprecise/superseded teachings (`corpus/lessons/round-25.md:184-208`). **Check:** for each new/changed row, independently open its exact URL and verify the dated located quote and scope against the cited source report. **Small correction:** admit no row on search-result snippets or inherited “opened” status; keep unopened leads out of the registry.

7. **Medium — report can overclaim freshness or source calibration from metadata-only checks.** C2 derives due dates from a recorded schedule; C3 checks a local ID/status/used-by and bare-date condition, not that a source supports the entry. QUALITY explicitly separates source access/topic/support/truth (`corpus/QUALITY.md:28-31`) and full criterion 6 also requires URL/path and exact anchor (`:17-23`). **Check:** independent sentence-to-evidence review of the final report and cited entry; every “fresh/verified/source supports” claim must have matching source-level evidence, otherwise be labelled policy-derived/inference. **Small correction:** describe C2 as schedule-derived and C3 as a scoped metadata-link screen, not source-truth verification.

8. **Low — selftest slowdown is not captured by the hold.** Holds require PASS and the first 161 case lines to match, but no selftest-time bound is registered (`round26-claims.md:122-125`; baseline log:66-67). **Check:** paired fixed-host base/candidate repeated selftest wall-time comparison, with an acceptable delta declared before adjudication. **Small correction:** keep added selftest fixtures bounded and measure time rather than treating PASS as an operability result.

VERDICT: Main risks are the untested tail-NUL interaction and C3's legacy/path-identity false-clean or false-drift cases; add the listed discriminating checks before accepting the affected axes. Installs: none.

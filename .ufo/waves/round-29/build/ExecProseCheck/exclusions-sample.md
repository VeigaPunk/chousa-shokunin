# Exclusion forms sample

These identifier forms must not be flagged even in prose:

sha256 sha512 sha1 md5 base64 utf8 x86 arm64 ipv4 ipv6
h1 h2 h3 h4 h5 h6
S046 s047 S999 r29 R44

These must be flagged:

all69 proposal64 diagnosis53 on2026 at most25

Also flagged outside code spans only: `all69` stays silent inside backticks.

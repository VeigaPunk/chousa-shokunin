- **Medium — JSON fields are regex-scanned, not structurally parsed** (`tools/research-gate.sh:1082-1100,1415-1449`): `[INFERENCE]` Repro with source `A\nx\n`: `{"id":"x","source":"src","span":"A","expect":"supported","li\u006ee":"2"}` is a valid escaped `line` key but is ignored, so the required line-2 binding is bypassed; `{"id":"x \\\"line\\\":\\\"999\\\"",...}` falsely detects a field inside a string; `{"line":null,"line":"1"}` accepts an ambiguous duplicate; `{"...","bad": }` is not rejected as malformed JSON. Ordinary space around `:` is handled. Impact: C1/C2 field semantics can be skipped or spuriously applied, contrary to SentinelContract31.md:19-20. Source is capped at 8 MiB, but claim/span length and occurrence count have no budget. Remediation: one linear scan/incremental line counts, with an explicit input/work limit.

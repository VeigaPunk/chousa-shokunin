# Sentinel C1 security review
Axes: operability (lock liveness), coverage (manifest target identity). **Verdict: BROKEN** — C1’s locked-path probe can be redirected and corrupt JSONL; no C1/C2 counters run.
**MEDIUM — availability, documented behavior:** a local reader can open a shared manifest `O_RDONLY` and hold `LOCK_EX` (`readonly_open=true exclusive_lock=true mode=0o644`); landed `verify-all --json` timed out after 4s with 0-byte manifest, while base appended under the same lock. Only callers using that path block. `tools/research-gate.sh:3284-3296`, docs `:214-216`; frozen C1 requires exclusion (`claims.md:23-28`). Smallest mitigation: bounded lock wait, fail closed.
**LOW — symlink redirection, pre-existing:** static `--json` symlink to a regular file outside `--root` is accepted and both base and landed append to its target (rc=0, two valid JSONL lines); checks follow links (`tools/research-gate.sh:3145-3152`), `exec {jfd}>>` follows too (`:3292`), as base `>>"$JSON_ARG"` did (`base-gate.sh:3199`, copied from base SHA). Privileged consumers could append as their UID; open with `O_NOFOLLOW` and fstat/reject symlinks.
**MEDIUM — C1 integrity/TOCTOU:** retarget symlink A→B after landed gate locks A but before `tail "$JSON_ARG"`; controlled probe produced `opened_fd_is_A=True A_locked_at_probe=True A_valid_jsonl=False` (object glued to A), whereas base wrote B clean (`A_valid_jsonl=True B_line_count=2`). The locked FD writes A but `tail` reopens the path at `:3292-3306`; probe through the same opened inode or fail if identity changes.
FD lifecycle: section subprocesses precede the open (`:3213-3229`); explicit close at `:3310` precedes printf-only output (`:3313-3335`). `tail/od/tr` run inside the lock section; Bash probe showed child inherits FD before close and not after.

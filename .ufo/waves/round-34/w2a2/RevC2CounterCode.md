## Answers to the assigned hunt questions — no false-pass harness bug found
1. **Crash/timeout/no-DRIFT scored 'none' → hides a real pass? No — fail-closed.** Parsing happens only under `if not timed_out and rc == 1 and drift:` (`:336`). Any rc≠1, missing `RESEARCH_GATE: DRIFT` (startswith, stdout lines only, `:335`), or timeout leaves `observed` empty → all 37 records score `none` → `DEADZONE_MATCH=0/37`, counter rc=1, `predicate_holds=false`; the cause is preserved in the receipt (`gate_rc`, `gate_timed_out`, `gate_stderr_tail`). Demonstrations (my stub gates in `stubs/`, receipts in `receipts/`): crash-after-printing-CLAIM-lines rc=2 → `r-s_crash.json` 0/37 `gate_rc=2`; rc=0 + lines → `r-s_zero.json` 0/37 `gate_rc=0`; rc=1 without DRIFT → `r-s_driftless.json` 0/37; timeout (patched `GATE_TIMEOUT_S=2` copy vs 5 s sleeper) → `r-s_time.json` 0/37 `gate_timed_out=true`, `gate_rc=null` (correct: no rc exists). A crashed gate can only lower the count, never raise it. Per-record `none` (never a pass) is also structural: `truth` values are only supported/unsupported/mislocated.
2. **Duplicate CLAIM id:** second occurrence sets `observed[cid]="none"` (`:346`) → conservative miss. `r-s_dup.json` (stub prints every id correct, first id twice): 32/37, miss `cbfa0ea5ed9 … observed=none`. Ids not in truth are ignored (`r-s_foreign.json` 0/37 with 37 fabricated ids). Fixture ids are unique by construction (regen loop in `generate`).
3. **LINE_RE / FIND_LINE_RE over-matching:** only gate **stdout** is parsed; stderr is truncated to a 2000-char receipt tail and never scanned — stub emitting perfect CLAIM lines on stderr + DRIFT/rc=1 on stdout scores 0/37 (`r-s_stderr.json`). `LINE_RE` (`:95`) demands a field after `observed=` (trailing space): lines without it do not parse (`r-s_nospace.json` 0/37), and the real gate always prints `… observed=$observed source=$src at=$at verdict=$verdict` (research-gate.sh:1967) so genuine output parses — witnessed by every 37/37 run. `FIND_LINE_RE` (`:96`) matches the real emitter format `FINDING $id severity=$sev surface=$surface obs=$obs` (research-gate.sh:448–451). Fixture text (lowercase letters, space, newline) cannot forge `CLAIM id=`/`FINDING` lines. Finding-rule is symmetric: FINDING on a supported-truth record → miss `supported+finding-set` (`r-s_extra.json` 36/37); missing FINDING on mislocated-truth → miss (`r-s_finding.json` 35/37, `r-s_dup.json`).

1. **Counterexample to Erratum 2's remaining self-consistency claim:** E3/38468 is internally contradictory under the actual C2 predicate, not merely unauthenticated. `verify-receipts.py:159–162` explicitly skips *_contains; `c2-count.py:258–264` evaluates them. Smallest safe correction: mirror the counter's contains semantics in offline re-derivation, and add a resealed wrong-reason regression; do not call substring matching an “exact line” check (claims:189–191).
2. **Authorship boundary versus integrity:** E3/38467 needs NO rerun, merely copying frozen expectations into observations; E3/38469 additionally permits false identity labels. No-authorship is therefore an honest, substantive LIMIT, not itself a kill: reproducing an indistinguishable statement is exactly what an unauthenticated checksum permits. But “integrity” must mean only current supplied-file digest equality/body checksum, not tamper evidence from an original producer, observation truth, historical execution or repository membership. Smallest correction: say this explicitly and bind/ignore the decorative identity fields consistently. No new authentication system is required by the narrowed claim.
3. **Residual honest claim:** under a clean caller environment, the final C1 counter reproduces seven named observations (7/7 versus both bases' 2/7); final C2 reproduces seven named pipeline checks (7/7 versus r37-counter 0/7), including 7/7 on the unfixed gate independently of C1. Offline verification checks supplied-file hash equality, family/predicate labels, table-relative census/expect ties, selected observation equalities and arithmetic. Until finding 1 is corrected, even full predicate self-consistency is NOT certified. Neither producer identity, execution occurrence, true observations nor immutable executing bytes are certified.
4. **Erratum 7 cleanup is still too broad:** E5 contradicts unqualified “refuse with exit 2 without leaving a stale ... receipt.” C1:214–225 and C2:283–303 return before deletion at C1:239–242 / C2:311–314. Smallest correction: delete the designated stale output before every refusal path, or explicitly narrow the textual guarantee to refusals after input validation; preserve evidence of that boundary. Impacts operability/calibration, not a necessary tradeoff.
5. **Erratum 8's byte-history guarantee exceeds endpoint sampling:** C1 loads expectations at :226 before hashing at :235; C2 does so at :298 before :307. No atomic snapshot ties parsed bytes to hashed bytes; pre/post equality also cannot exclude temporary A→B→A changes. These are source-grounded counterexamples, NOT executed races. Smallest correction: hash and parse one immutable byte snapshot, and describe gate binding as sampled equality unless execution uses a pinned snapshot. Also correct the residual seed/temp-namespace error (claims:152–153); seed is metadata, not fixture randomness. Impacts calibration.

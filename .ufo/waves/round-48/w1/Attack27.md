## Specific, testable fix (proposal; no predicate frozen)

For a future pre-score C1 claim, add a distinct precision leg that uses a **new, independently authored and hash-pinned set**, not these repeated HeldOutA literals. Include at least: (i) correct negated-phrase paraphrases with unlisted `nonexistent`/`untraceable`; (ii) correct negator farther than three preceding words; (iii) an affirmed phrase whose nearby negator scopes a different occurrence (a05-shaped); and matched nearby-in-scope controls so a blanket pass cannot score. Assert expected exit/finding class per case, print `CORRECT_PASS=n/N`, `FALSE_REFUSAL=n/N`, require a declared ceiling on false refusals and a minimum denominator, and include do-nothing plus always-refuse controls. Freeze case bytes/digests and expected verdicts before any scoring; run against both the candidate and the R47 baseline. This measures precision without loosening the R47 frozen rule. Separately add the five surviving refinement killers as counter cases and require each targeted mutant to fail, while keeping correct positives passing. Acceptance should be declared before scoring; no threshold is recommended as frozen here.

# Attack28 — precision gate adversarial review

## Verdict

**Current precision gate is not a usable operability/calibration gate: a do-nothing candidate passes.** `corpus/evidence/round48/precision-count.py` measures only correctly reasoned bullets and accepts solely on `returncode == 0`; it has no flip/control leg. The work is useful as a measured false-refusal probe, not as a candidate correctness predicate. Do not freeze/admit it as a precision gate in this form.

## Direct falsifier (measured)

Commands, from lane root:

```text
python3 corpus/evidence/round48/precision-count.py
p01=PASS rc=0; p02=PASS rc=0; p03=REFUSED rc=1; p04=REFUSED rc=1
p05=PASS rc=0; p06=PASS rc=0; a01=PASS rc=0; a02=PASS rc=0

python3 corpus/evidence/round48/precision-count.py --tool /tmp/chousa-r48-attack28/do-nothing.py

```

The temporary `do-nothing.py` was a three-line `sys.exit(0)` program; scratch was `/tmp/chousa-r48-attack28`. Thus the counter positively accepts a candidate with no inference/grounding/polarity behavior. This is a **critical gate-design defect**, not a hypothetical risk.

## Concrete shortcut findings

1. **No negative oracle (critical).** `precision-count.py:11-24` declares 12 all-correct cases; `:44-52` counts only rc=0 and succeeds when all 12 pass. No wrong-polarity examples are presented, so the all-zero candidate above passes. Add paired, grounded adversarial flips and require named `INF_POLARITY_FLIP` plus exit 1 for each, while requiring correct bullets exit 0. Assert both expected outcome and diagnostic code (not just exit status); make sure all flip cases remain grounded so a generic grounding failure is not mistaken for polarity detection. Existing R47 junk cases can seed mechanics but are publicly fixed and cannot alone serve as a blind test.

2. **Labels and case identity are not tested.** The runner writes filenames/headings `p01`…`a06` (`:39-43`), but tests neither stdout/stderr nor finding identity (`:47-50`); a candidate may return constant codes or branch on those labels. A new gate should use opaque per-run identifiers/paths, and verify semantic outcome independently of labels. Include a constant-0 and constant-1 candidate control; both must fail for distinct reasons. Merely randomizing labels is insufficient if a candidate can memorize the fixed bodies.

3. **Fixed fixture memorization remains an escape hatch.** All twelve literal quote/body pairs are embedded in `CASES` (`:11-24`), and fixed committed R47 inputs are already observable. A candidate keyed to those exact strings could selectively produce expected outputs without implementing polarity behavior. Keep fixed cases as reproducible regression evidence, but do not let them establish generalization. Include separately generated/held-out cases built from local grounded spans and independently authored paraphrases, hidden from the candidate/counter until candidate identity is frozen; report seed and generated bytes after scoring for reproduction. Test multiple seeds or a committed held-out rotation, not one known seed. Do not claim randomization makes semantic gaming impossible; the robust claim is bounded generalization to a blinded held-out set.

4. **Outcome checks must distinguish refusal from crash/usage failure.** The current counter accepts any rc=0 regardless of diagnostics and treats all nonzero results identically as `REFUSED` (`:47-50`). For the negative arm require rc=1 and the specific polarity finding; require correct arm rc=0 and no finding; rc=2, timeout, malformed output, unrelated failure, or missing expected diagnostic must fail. A diagnostic string alone is also insufficient: pair it with the intended exit contract and grounded case setup.

## Calibration evidence / residual limitation

Measured local run is 9/12 correct bullets accepted (3/12 refused), matching the two earlier HeldOutA refusals p03/p04 and a05. Specifically `p03` uses `nonexistent`, `p04` puts `cannot` outside the window, and `a05` has `not` whose scope is the second build-date mention; `tools/inference-ground.py:317-348` uses stem overlap and local windows. These are concrete calibration costs; the 12-case set is still small and not an estimate of population false-refusal rate. Do not describe C1 as broadly reliable based only on its positive fixture score.

## Proposal (not a frozen predicate)

Require a two-sided contract: correctly reasoned grounded examples pass; matched opposite-polarity grounded examples refuse specifically as `INF_POLARITY_FLIP`; both constant-exit controls fail. Preserve the exact probe corpus and byte hashes, but supplement it with an independently held-out, varied suite whose labels/paths and seed are not exposed before scoring. Publish each case, seed, output, and denominator afterward, stratify correct-bullet false refusals by class, and treat any rule/case/floor change after scoring as a new predicate—not a repair to a scored one. This is a proposal only; no predicate is frozen and no post-score change is recommended.

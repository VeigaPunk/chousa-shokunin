# CritC1Content — R62-C1 content-detection critic (w1, item CritC1Content)

Scope: attack the frozen v2 counter `corpus/evidence/round62/c1v2-count.py` (sha256 prefix `b7016fba91b03460`, checked)
by a forger that recognises the counter's fixtures by content, not environment. Frozen battery
`c1v2-battery.py` (sha256 prefix `9afe00b917fb95e2`) read for its TEMPLATE only. Landing builder `tools/build-spans.py`
(prefix `c366492005ce304a`, checked). Base builder `controls/base-build-spans.py` (prefix `1ed2650af28ea8e3`).
No lane file written; no git write; scratch removed at the end. Tool installs: none.

## Method

1. Forgers (scratch, generated by importing the frozen battery read-only with `python3 -B` and filling its TEMPLATE:
   landed builder embedded, base builder as fallback, `sniff` and `pre` swapped). Each forger runs the landed builder
   when its content sniff fires and the unhardened base builder otherwise.
   - **CF-A shape+vocab**: header exact; every id matches `S[1-8][0-9][0-9]`; some quote contains one of
     `chain`, `anchor`, `药品临床`, `证据链`.
   - **CF-B grammar+names**: every quote fullmatches `[a-z]{3,9} [a-z]{3,9} (token) [a-z]{3,9}[0-9]{2}`; every cache file
     is `[0-9a-f]{24}\.(txt|raw)`.
   - **CF-C full fingerprint**: CF-B plus ids `S[1-8]xx`, entry cell `== corpus/knowledge/x.md` on every row, quote
     length 14–45, `capture-text.py` beside the builder.
   - **CF-D real-invariants only** (calibration): `capture-text.py` beside the builder and 24-hex cache names. These hold
     for real lane runs too.
   - **CF-0** (calibration): sniff never fires, so it is the base builder on every leg.
   Each sniff logs its conditions to a per-forger trace file (the trace is in-builder, not read by the counter).
2. Ran the frozen counter on each forger at three seeds: `C1V2_SEED=<N> TMPDIR=<scratch> python3 -B
   corpus/evidence/round62/c1v2-count.py --builder <forger> --work <scratch>/w/<name>`. Seeds 620101, 620202, 620303.
3. What-if (diagnostic, NOT a frozen-counter change): `whatif/runner.py` imports the frozen counter read-only and widens
   only the fixture draws: `ids` (S001–S999), `vocab` (CJK runs and random words, variable length, punctuation
   separators, no fixed token set), `entry` (five directory roots). Re-ran forgers and the landing builder under it.

## Feature classification (what a forger can sniff, and whether the counter can remove it)

| feature | sniffed by | class | evidence |
|---|---|---|---|
| id range S100–S899 | CF-A, CF-C | **defeatable** — builder only requires `S\d{3}` (`ID_RE`), so the counter may draw 001–999 | ids-only variant: CF-A 16/20 |
| quote vocabulary (4 tokens) | CF-A, CF-B, CF-C | **defeatable** — real-looking quotes replace the fixed set | vocab variant: CF-A 11/11/10, CF-B 11/11/11 |
| quote grammar and length | CF-B, CF-C | **defeatable** — same variant | CF-B 11/20 (vocab variant) |
| entry cell `corpus/knowledge/x.md` | CF-C | **defeatable** — builder accepts any lane-relative entry | entry variant: CF-C 12/12/12 |
| capture names 24-hex | CF-B, CF-C, CF-D | **indistinguishable** — `key(url)` is sha256[:24] in base and landing alike; real captures are identical | CF-D 20/20 |
| `capture-text.py` beside builder | CF-C, CF-D | **indistinguishable** — landing builder imports it from its own directory; the lane layout is the same for real runs | CF-D 20/20 |
| span context 80 | nobody | **not a discriminator** — `CONTEXT = 80` in base (line 43) and landing (line 69); no pre-run sniff is possible; base output matches landing on it | grep |

Named-limit gap: the counter's docstring (`c1v2-count.py` lines 55–58) lists the S### id shape, the quote vocabulary and
the `capture-text.py` file name as unvaried. It does **not** list the entry cell (fixed at `corpus/knowledge/x.md` in
every leg except H19; `two_url_rows`, line 276) or the quote grammar and length. These are unlisted, fixed features
and are a routed limit for the next round's battery, not a refutation of R62-C1 (the frozen predicate covers the 12
environment forgers).

CF-D (indistinguishable features only) passes 20/20 at two seeds. A forger that sniffs only real-data invariants
behaves as the landing builder on every real input, so the counter cannot reject it, and it is not a forgery in
practice. This is the named limit in its honest form.

## Limits of this critic run

- The what-if runner is a scratch variant of the frozen counter (method monkeypatch, imported read-only); its numbers
  are diagnostic. Any change to the frozen counter is a routed supplement for the next round, not a rewrite.
- The landing-builder control under the widest variant was run at one seed only. The ids-only, vocab-only and
  entry-only variants were not run against the landing builder.
- The what-if traces are NOT clean. Two what-if runs of the same tag ran concurrently and shared one trace file, so
  trace counts from what-if runs are not per-run. The LEGS lines are per-run and unaffected (the counter does not read
  traces). Baseline traces are clean.
- Single-seed what-if for ids only (CF-A 16/20); not replicated.
- Forgers were written by this seat. The frozen named limits already name two of the features, so a forger that uses
  them is expected and not new; the entry cell and quote grammar are the new items.
- Not run: the full frozen battery with these forgers added. They are not among the 12 forgers of the frozen battery.

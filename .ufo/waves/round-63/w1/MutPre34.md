## Method

- Read `controls/run-c1-controls.py` first: it holds M01–M16. My 14 mutants are single-substitution edits of the
  reference bytes, none of which repeats an M-id (M07 removes the whole `:N` strip; n08 removes only `-M`. M15 anchors
  the heading with `\s*$`; n06 anchors with `\b$`, a near-duplicate in spirit, disclosed below).
- Driver: each mutant ran the frozen battery with `--only CLEAN,<expected legs>` and `--jobs 2`, prefixed by the
  command `python3 -B c1-battery.py --tool <mutant> --fleet /home/vgpnk/Projects/shokunin --work <scratch>/b-part-<n>
  --jobs 2 --only ...`. A mutant is KILLED when a leg prints `LEG <id> <kind> FAIL` (the tool misbehaved on that leg).
  Survivors (no partial kill) got one full run, `--jobs 2`, no `--only`.
- Exact kill probabilities for the random-pick legs (D06, D14) were computed by running each mutant on all 40
  lesson picks (`probe.py`, not frozen, scratch only); the battery draws its pick uniformly from the same sorted list.
- Gap demonstration: scratch fixtures (lessons + SHONEN + placeholder targets) run through reference and mutant with
  `--only G03|G04`, the input each survivor misses. Output is `probe.log` / `probe-results.json` in scratch.

## Survivor classification

None of the ten survivors is an equivalent mutant: each has a distinguishing input that the gate's own written rule
(claims.md, G03/G04) covers. They are control gaps. Named battery leg that would kill each:

- n01 `## Gates` heading: a defect leg planting a lesson whose only heading is `## Gates` (expect G03 FAIL). The claim
  says `## Gates` does not count, so this is a direct gap in the frozen rule's own named case.
- n02 inline `## Gate` mention: a defect leg planting a lesson with `## Gate` text in the body and no heading (expect
  G03 FAIL). Makes the kill deterministic (it is 0.32 today).
- n05 `### Gate` heading: a defect leg planting a `### Gate` heading and no `## Gate` (expect G03 FAIL). Makes the
  kill deterministic (it is 0.10 today).
- n07 bare filename: a defect leg adding `` `GONE-zz.md` `` to SHONEN (expect G04 FAIL); the rule says a
  whitespace word ending `.md` is a pointer.
- n08 `:N-M`: a benign leg adding `` `corpus/README.md:3-5` `` (expect G04 PASS).
- n09 leading `(`: a benign leg adding `` `(corpus/README.md)` `` (expect G04 PASS).
- n10 trailing punctuation: a benign leg adding `` `corpus/README.md;` `` (expect G04 PASS).
- n11 URL span: a benign leg adding `` `https://…` `` (expect G04 PASS). Rule: an `http:`/`https:` word is not a pointer.
- n13 multi-line span: a defect leg with a span across two lines holding a missing path (expect G04 FAIL). Spec
  ambiguity: the claim does not say whether a span may cross a line; CommonMark allows it, the reference does not.
  This needs an L1 decision, not only a leg.
- n14 tab-separated: a benign leg with `` `corpus/README.md<TAB>SKILL.md` `` (expect G04 PASS).

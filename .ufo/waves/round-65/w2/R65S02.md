## 3. Loaded-module identity (is the pinned file really the module docs?)

First attempt used a naive text split to compare the file's `__doc__` literal
with the imported `hashlib.__doc__`; it returned False — **that was my
extraction bug** (`rsplit('"""')` grabbed a later docstring's closing quotes
in the 255-line file), not a source defect. Redone with `ast` on the exact
literal:

```python
import ast, hashlib, pathlib
src = pathlib.Path('/usr/lib/python3.14/hashlib.py').read_text()
tree = ast.parse(src)
filedoc = next(n.value.value for n in tree.body
               if isinstance(n, ast.Assign) and any(getattr(t,'id',None)=='__doc__' for t in n.targets))
print('loaded-module __doc__ == file __doc__ literal:', filedoc == hashlib.__doc__)
```
Output:
```
loaded-module __doc__ == file __doc__ literal: True
```
Also: `hashlib.__file__` → `/usr/lib/python3.14/hashlib.py`.

So the imported module's documentation is byte-identical to the pinned file's
`__doc__` literal — the pin refers to documentation the interpreter actually
exposes, not merely a file on disk.

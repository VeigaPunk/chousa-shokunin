Host interpreter used by the frozen command `python3 -B ...`:
  $ python3 -VV
  Python 3.14.8 (main, Oct  2 2026, 10:23:31) [GCC 16.2.1 20260810]

The battery's archive() does `tf.extractall(dest)` with no filter (forgeries-r93.py line 51).

(observed source lines: /usr/lib/python3.14/tarfile.py:2444-2448), so extractall applies the 'data'
filter, which raises AbsoluteLinkError on an absolute symlink.

# receipt R96SentinelC1-battery-writes-lane-index
# FINDING (severity: low): the battery's own docstring says it is 'Read-only on the lane
# (git show, git status)'. 'git status' is NOT read-only on the lane: it refreshes the
# stat cache and REWRITES the lane's .git/index. So the round-96 battery writes a file
# OUTSIDE --work, into the lane's .git directory, on every run -- contradicting both
# 'Writes only under --work' and 'Read-only on the lane' in its own header.
# (The bytes git writes are a stat-cache refresh, not content; the lane's tracked files
#  and HEAD are unaffected. The claim's 'lane status unchanged' is unaffected too.)

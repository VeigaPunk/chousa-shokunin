# leg FIRST (selftest(tool), cwd = the lane root, ambient HOME), long before the NO_WRITE
# leg takes its 'before' snapshot. So a lane write the selftest performs is ALREADY in the
# baseline. And 'git status --porcelain' prints only path + status letter, so a second,
# further change to the SAME path is byte-identical in the before/after strings.

## Decision table

| Situation | Do | Never | Warrant |
|---|---|---|---|
| a scoping question maps what exists | frame it as population, concept and context | force an intervention and comparator into it | Q1 (S210) |
| the question cannot be stated in one sentence | rewrite it before any search is run | start searching on the unclear question | Q2 (S210) |
| eligibility criteria are being drafted | derive one include and one exclude line per element | write criteria that no element of the question produced | Q3 (S211) |
| the protocol changed after searching began | record the deviation and its justification in the report | silently report the changed protocol as planned | Q4 (S209) |
| a review PICO is being fixed | use it as the eligibility boundary for studies | treat it as the comparison each synthesis answers | Q5 (S008) |

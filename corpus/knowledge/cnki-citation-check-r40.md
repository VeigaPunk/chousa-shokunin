#### Inference

- **The second state is a diff, not a verdict.** The orange state does not say the citation is wrong: the record was found and the manual names the part that differs — `但是引文中有某一部分的信息与源内容不同` — with the part surfaced on hover and the list content marked red. As this 2020 copy states it, the checker reports *which* part of the citation misses, a finer output than one correct-or-incorrect flag (`S105`).
- **The three states keep a coverage outcome apart from a support outcome.** The first state is `第一类是“没找到”` and the third is `第三类则是绿色的标识`; only the middle state's text says a record was found and a part differs. So the 2020 copy separates nothing-matched from matched-and-identical from matched-and-partly-different, and a lane that reported one of those three as another would lose a distinction the vendor draws (`S105`).
- **The result row carries the matched work, not only the verdict.** The list shows 状态, 篇名, 作者 and 文献来源, and the title links to the cited work's record — `列表中的“篇名”可以点击，链接到该引用文献的详细信息。` — so a reader can re-open the matched work from the result row; the 2020 copy names no other handle, 标识符 0 in the capture (sweep in Unknown) (`S105`).
- **The check is against a named pool, as this copy states it.** The definition fixes the checking source as `以“中国知网”的文献资源为核对源内容` and §6.1 names no second pool — 未收录 0 and 匹配 0 in the capture (sweep in Unknown) — so the 2020 copy describes a closed-corpus check rather than a check against the open web (`S105`).
- **In the lane's four-observation frame, the orange state is support reported as partial.** `corpus/knowledge/claim-support-states-r24.md` separates access, relevance, support and truth as four failable observations; the 2020 copy keeps access and relevance (a record was found and it is the cited work) and reports support as a located difference — the shape that file's observation 3 needs and does not itself supply (`S105`).
